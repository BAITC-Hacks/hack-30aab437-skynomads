# Local UI fonts

Outfit is the primary family (Latin and numerals). It does not include Cyrillic;
Inter supplies Cyrillic and Cyrillic Extended glyphs. The UI uses only weights
300, 400 and 500. Both families are variable WOFF2 subsets distributed under
the included SIL OFL 1.1 license. Fonts are bundled locally, with no runtime
request to Google Fonts.

Source URLs (Google Fonts CSS API, retrieved 2026-09-23):

- `Outfit-Latin.woff2`: https://fonts.gstatic.com/s/outfit/v15/QGYvz_MVcBeNP4NJtEtq.woff2
- `Outfit-LatinExt.woff2`: https://fonts.gstatic.com/s/outfit/v15/QGYvz_MVcBeNP4NJuktqQ4E.woff2
