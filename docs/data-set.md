## 2. Каталог мероприятий

## 3. Расчёт Score

1. Для каждого района `d` и показателя `k` новое значение: `I′(d,k) = clip(I(d,k) + Σ[эффект(m,k) × (8 − лаг(m))/8] + бонусы(d,k), 0, 100)`. Районные меры действуют только в выбранном районе, городские — во всех пяти; синергии фиксированные и от лага не зависят.
2. Балл района: `D(d) = Σ[вес(k) × I′(d,k)]`.
3. Средний городской балл: `D_avg = Σ[доля_населения(d) × D(d)]`.
4. Итог: `Score = 0.7 × D_avg + 0.3 × min(D(d)) − 1.0 × N_crit`, где `N_crit` — число пар «район × показатель» со значением **строго меньше 40** после применения эффектов.

| Код показателя | T1 | T2 | E1 | E2 | S1 | S2 | B1 | B2 | C1 | C2 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Вес | 0.10 | 0.10 | 0.09 | 0.11 | 0.11 | 0.11 | 0.09 | 0.09 | 0.10 | 0.10 |

Сумма весов = 1. По направлениям: транспорт 0.20; экология 0.20; соцсфера 0.22; безопасность 0.18; сервисы 0.20. Общий результат по городу формирует 70% Score, слабейший район — 30%; каждый критический показатель уменьшает Score ещё на 1 балл. Неиспользованный бюджет бонуса не даёт.

Исходный Score без мероприятий: **52.56** (округлённое `D_avg ≈ 56.86`, минимум районов 49.18, две критические пары — S1 и S2 в Нуре).

## 4. Правила набора

- Бюджет: **100 условных единиц**; остаток не сгорает и не влияет на Score.
- Выбрать **ровно пять** разных мероприятий, каждое максимум один раз. Порядок не влияет на результат.
- Не больше двух мер из одного направления; при пяти мерах это означает минимум три направления. Меры не обязаны покрывать все пять направлений.
- Для районной меры указать существующий район, для городской район не указывать.
- Запрещены несовместимые пары с учётом их условия по районам.
- Для невалидного набора Score **не вычисляется**; валидатор сообщает причину.

## Роль AI

LLM получает уже рассчитанные Score, дельты по районам и показателям, вклад мер и сработавшие синергии. Он объясняет сильные стороны, риски и компромиссы; **числа считает backend, а не LLM**. В приложении для этого используется OpenAI API. Без доступного API расчёт Score остаётся доступен, а отсутствие AI-объяснения показывается явно.
