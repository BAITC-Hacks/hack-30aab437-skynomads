Толкование пяти направлений согласовано командой: доступны все пять, выбранных мер ровно пять, максимум две на направление, следовательно минимум три направления. Это правило из датасета, а не требование «строго одна мера в каждом направлении».

Из опциональных пунктов реализована визуализация районов до/после. Сравнение команд, случайные события, история, автопрезентации и оптимизатор плана не реализованы и не заявляются.

Среда: Windows, Node.js 24.19.0, Yarn Classic 1.22.22, headless Microsoft Edge с реальным viewport 1536×1024 и эмуляцией 390×844.

2. `yarn smoke` — built UI, локальные WebP/WOFF2, каталог, невалидный ввод 400, Score 56.54 и явная ошибка отсутствующего ключа PASS.
3. `yarn smoke --live` — реальный AI-ответ для демо PASS.
4. Чистая копия рабочего дерева во временной папке `submission-clean-20260923`, без Git, `.agents`, зависимостей, сборок и локального `.env`: `yarn install --frozen-lockfile --non-interactive`, `yarn verify`, `yarn smoke` PASS. Это снимок текущих файлов, **не clone ещё не опубликованных изменений из origin**.
5. В браузере запущена production-сборка из чистой папки, UI/API на одном origin: ошибка пустого плана, демо, пять слотов, Escape, расчёт 95/5/56.54, настоящий AI-отчёт, таблица 10 показателей и все 14 картинок в пяти категориях — PASS. На 390px `scrollWidth = 390`. Для живого вызова существующий локальный ключ передан процессу через окружение; в чистую папку и отчёт он не записывался.
6. `.env` исключён Git; `.env`/private-key файлы не найдены в tracked paths и истории этих путей. Поиск распространённых credential patterns в tracked text не дал совпадений. Это не гарантия отсутствия любых возможных секретов — перед отправкой команда должна проверить итоговый staged diff.

Предупреждения сборки: Three.js vendor bundle около 950 KiB и большие исходные PNG. Runtime использует WebP-миниатюры; локальная демонстрация прошла. Новая система рендера/оптимизация зависимостей не добавлялась перед сдачей.

## Демонстрация за две минуты

**До начала:** `yarn verify`, `yarn smoke --live`; затем `yarn serve` и открыть http://localhost:7000. Убедиться, что ключ и квота действуют. Если на 7000 уже есть сервер, остановить именно свой прежний экземпляр.

| Время | Действие и тезис |
| --- | --- |
| 0:00–0:20 | «Мы показываем, как пять городских решений при бюджете 100 меняют качество жизни пяти условных районов». Показать карту, каталог, базу 52.56. |
| 0:20–0:45 | Открыть «Решения» → «Загрузить демо-набор». Показать стоимость 95 и назначения: M7/M8/M10 — Нура, M5 — Сарыарка, M12 — весь город. |
| 0:45–1:05 | Закрыть план: показать подсветку участков. У городской меры пять отметок, но стоимость учитывается один раз. |
| 1:05–1:30 | «Рассчитать результат». Показать 56.54, остаток 5, три части реального AI-анализа. Пояснить: «Числа считаются по формуле на сервере; AI только объясняет факты». |
| 1:30–1:45 | Открыть показатели и сравнить районные изменения; показать синергию M10 + M12. |
| 1:45–2:00 | Удалить одну меру и попробовать расчёт: понятное предупреждение. Завершить: «Данные синтетические; запуск, конфигурация и проверка полностью описаны в README». |

Не называйте модель реальным прогнозом для Астаны или production-ready системой. Не выдавайте гипотезы AI за доказанную причинность. При недоступном OpenAI покажите явную ошибку и сохранённый числовой Score; полноценное AI-демо требует рабочего ключа.
